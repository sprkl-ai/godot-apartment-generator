# Godot Apartment Generator

Отдельный генератор планировок для разработчиков игр на **Godot 4 / 2.5D**.
Данные и алгоритм отделены от демки; игровые сцены, ассеты и сервер не нужны.

Откройте `project.godot` в Godot 4.7.1, дождитесь импорта и нажмите F5.
Введите сид и номер этажа. Слои показывают мебель, консервативный запас прохода,
граф комнат и полную фоновую застройку. Колесо масштабирует, средняя/правая
кнопка перемещает карту, щелчок выбирает комнату. Walk test включает WASD.
Кнопка **2.5D preview** открывает тот же этаж с примером 3D-геометрии.

Чтобы использовать алгоритм в своей игре, скопируйте `core/` и `data/`,
вызовите `EndlessGenerator.new().generate(seed, floor, scheme)` и стройте свой
визуал по `RoomDef.areas`, `wall_segments`, `colliders` и дверям.
Пример готового 3D-сборщика — `examples/level_geometry_3d.gd`, метод `build(data)`.

Проверено на Godot 4.7.1. Результат совпадает с исходной игрой для девяти
эталонных планировок; алгоритм не был заменён похожим упрощённым генератором.
Предупреждения консервативной проверки проходов показываются открыто: они не
равнозначны доказанной блокировке игрока. Проверяйте нужные размеры персонажа
своей физикой. Пример лестниц — декоративная геометрия, а не переход между этажами.
